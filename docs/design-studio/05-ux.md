# 05 · UX: editor anatomy, screens, flows and copy rules

This file is binding for every FE module. The mockups are at https://claude.ai/artifact/9Cwm9fMMTwDbG4DoN39Juw; their source is in `canvas/project/`.

**Base:** `plans/kpi-report/05-ux.md`. These parts still apply: principles 1–6, the canvas interactions, the per-element inspector content (now shown in the toolbar and drawers), the AI suggestion card, the checks panel, and the versions screens. This file replaces RS's S3 layout with the Canva-style anatomy below.

App chrome uses `src/ui` and the app tokens. **Report content** (inside a sheet) uses only the renderer and the report's theme.

## Principles (in addition to RS)
7. **Familiar to Canva users.** The people who make these reports already use Canva, so we reuse the patterns they know:
   - a left side rail with drawers;
   - a contextual toolbar above the page;
   - the Position panel;
   - the page strip and grid view;
   - Styles and shuffle;
   - Resize.

   We never use Canva's names for AI features ("Magic …"), its icons or its look.
8. **Data is the difference.** Every data-bound thing shows a small link mark. The Data drawer is one click away from any number. Unlinked custom data says so.
9. **One editor, two report kinds.** GHG and sustainability reports use the same editor. Only the Data drawer, the templates and the checks differ.

- **Rail tabs** (icon + label; the drawer opens on click, and clicking the same tab again closes it):

  | Tab | Drawer content |
  |---|---|
  | **Templates** | Whole-report templates (apply to all pages, with a confirm) and page layouts (add one page), filtered to this doc's kind and format. Search and tags. |
  | **Elements** | Search plus groups: Shapes, Lines and arrows, Frames, Grids, Icons, SDG, ESG graphics (scope diagram, value-chain strip, pillar marks), Data elements (big number, KPI tile, progress ring, callout, chart, table). Click to add at the centre, or drag to a point. |
  | **Text** | "Add a heading", "Add a subheading", "Add body text", plus text presets (kicker + title + body combos styled by the theme). "Insert data value" opens the picker. |
  | **Brand** | Brand kit logos (light and dark), palettes as swatch rows, fonts, and **Styles**: palette + font pairs with **Apply to all pages** and **Shuffle**. A link to edit the brand kit (Managers). |
  | **Uploads** | Drop zone, folders, the company's assets; "Generate image" (AI cover art, RS R13). |
  | **Data** | GHG kind: Scope 1 / 2 / 3, categories, sites, months, gases, intensity, base year. Sustainability kind: KPI search by topic and framework. Each item shows its value for the doc's year and approval state. Drag it onto the page as a big number, tile or chart (asks which), or click to insert at the cursor in text. Below: **Report details** (the report inputs form) with missing ones marked. |
  | **Charts** | Chart kinds as thumbnails (only kinds valid for the current data are enabled); "Custom data chart" at the bottom with the Unlinked badge. |
  | **AI** | The chat panel (S4). |
  | **Pages** | Page list with names, flow badges, hide/duplicate/delete; also opens grid view. |

- **Contextual toolbar:** it changes with the selection:
  - **text:** font, size, colour, bold/italic/underline, align, lists, spacing, Effects (shadow, outline, background), AI rewrite ▾;
  - **image or frame:** Replace, Crop, Flip, Filter (none / mono / brand duotone), Corner radius, Alt text;
  - **chart:** Edit data (opens the Data drawer on its binding), Chart kind ▾, Colours (brand series), Labels, Grey prior years;
  - **table:** Edit, Rows/columns, Style, Total row;
  - **shape or icon:** Fill, Border, Radius.
  - **Always:** Position, Transparency, Link mark (data source + approval date), Lock, ⋯ (copy style, duplicate, comment, Ask AI, delete).
  - **Nothing selected:** page Background, page Layout ▾, "Reset to layout".
- **Position panel** (it opens in the drawer area):
  - an **Arrange** tab: forward / backward / front / back; align to page, or to the selection when several are selected; Tidy up; X/Y/W/H in mm; rotation;
  - a **Layers** tab: reading order, drag to reorder, eye, lock.
- **Status bar:** speaker notes, the page strip (thumbnails, drag to reorder), the page counter, a zoom slider (10–400 %, Fit), grid view, and full screen.
- **Grid view** (mockup "Grid view"): all pages as thumbnails grouped by chapter, with titles, a Flow badge, hidden pages greyed, drag to reorder, multi-select, then Duplicate / Hide / Delete / Move to chapter.
- **Rulers and guides:** File ▾ → View → Show rulers, Show margins, Show bleed, Show guides; drag a guide out of a ruler; guides are stored per page and are not printed.
- **Shortcuts:** all of RS S3, plus Alt+⌘+1/2/3 for scroll / strip / grid view, ⌘K for the command palette, T for text, R for a rectangle, L for a line, C for a comment.

## S1 · Home (`/studio`, mockup "Home")
- "What will you design?" strip: **GHG report**, **Sustainability report** (disabled with "Needs KPI tracking" when off), **Board deck**, **One-page summary**, **Social card**. Each opens S2 preselected.
- **Readiness cards** for the latest period, one per kind:
  - GHG: approved and pending entries, sites covered, months covered, Scope 3 n/15 addressed, with a link to fix each gap;
  - sustainability: the RS readiness.
- **Recent designs:** a card grid with thumbnail, title, kind badge, format, status (Draft / In review / Approved / Final vN), edited when and by whom, and ⋯ (Duplicate, Resize, Rename, Delete).
- **Empty state:** "Design your first GHG report. We'll lay it out from your approved emissions."

## S2 · New design (`/studio/new`, mockup "Templates")
Four steps, one screen each, with a live preview on the right:
1. **Template:** a gallery for the kind with filters (format, look, pages) and search. Each card shows the cover and two inner pages rendered with *this client's* brand and data. "Blank A4" sits last.
2. **Scope:** year and year type, compare year, sites (default all), frameworks (GHG: GHG Protocol / ISO 14064-1 / BRSR P6 / ESRS E1; sustainability: GRI / BRSR / ESRS).
3. **Report details:** the report inputs (`01-contracts` §2.1), prefilled with their source shown ("From company settings"). Missing items are allowed and listed as "We'll flag these in checks".
4. **Words:** "Write text with AI" (default on), brand voice preview, leadership message (sustainability), cover image (upload or generate).

**Build** shows a progress list ("Laying out 22 pages… Writing the Scope 3 summary…") and then opens the editor.

## S4 · AI panel (rail tab AI, mockup "AI")
- **Chat** at the top: "Ask about this report or describe a change." Quick chips: *Write the executive summary*, *Explain the change in Scope 2*, *Draft exclusion reasons*, *Suggest a layout for this page*, *Check for missing disclosures*, *Make it more concise*.
- **Replies** are short text plus suggestion cards (RS S4 card: title, diff or ghost preview, "Based on" sources, **Accept / Try again / Discard**). Nothing changes on the page before Accept.
- **Selection-aware:** with an element selected, the panel header says "About: Scope 3 chart (page 11)".
- A brand voice note ("Writing in your brand voice · Edit") and the budget meter.
- **Design from a brief** (from S1 or the panel): "A 12-page GHG summary for our board, dark look, focus on Scope 3 suppliers" → 2–3 template + outline proposals as thumbnails → Accept builds a new doc.

## S5 · Brand kit and Styles (`/studio/brand-kit` and the Brand drawer, mockup "Brand and styles")
- **Brand kit page:**
  - Logos (read from the client's brand; Superadmin edits them as today);
  - Palettes (add, name, reorder; contrast badge per colour pair);
  - Fonts (heading, body; from the curated OFL set, RS R12);
  - Brand voice (textarea with an example and a "Try it" rewrite preview).
- **Styles in the drawer:** 6–12 preset cards (palette dots + "Aa" in the font pair). Hover previews the current page. **Apply to all pages**. **Shuffle** cycles colour assignments within the palette. Undo restores.

## S6 · Resize (top bar **Resize**, mockup "Resize")
- **Dialog:**
  - on the left, target formats with checkboxes: Board deck 16:9, One-page summary A4, Social square, Social 1.91:1, A5 booklet;
  - on the right, a preview of the first 3 pages of the selected target;
  - options: "Pages to include" (chapters), "Summarise text with AI" (default on when AI is on).
- **Create copies:** each copy opens as a new design linked to its source, with a "Made from GHG Inventory FY26" chip and "Source data changed" when its hash moves.

## S7 · Share, download, present (mockup "Share and download")
- **Share ▾:**
  - people with studio access (opens comments and @mentions);
  - "Request approval" (D14);
  - "Create view link" (Manager; expiry picker; copy; list with views and Revoke).
- **Download ▾:**
  - PDF (screen) and PDF (print: bleed, crop marks);
  - PNG (all pages or a range, 2× or 300 dpi);
  - Proof vs Final: final is disabled while checks block, with the reason shown.
- **Present:** full screen, arrow keys, the notes view on a second window, Esc exits.

## S8 · Checks and final (RS S5, plus GHG)
- **Groups:** **Must fix** / **Review** / **For info**.
- **GHG checks** each name what the standard expects in plain words and give a fix, e.g. "Scope 3 category 9 (Downstream transport) isn't reported or excluded. [Mark as excluded…] [Go to Scope 3 page]".
- **Generate final:** as RS, plus "Pending entries: 4. Approve them in Review before the final." with a link.

## S9 · Comments, tasks, approval and history (DS-13)
- **Comments:**
  - pins on elements;
  - a thread panel with @mentions (autocomplete of studio users);
  - "Assign as task" adds a checkbox and an assignee chip;
  - "Show resolved".
- **Approval bar** (when requested): "Approval requested from Asha · due 28 Oct", with Approve / Request changes for the reviewer.
- **Version history** (File ▾ → Version history):
  - a list of autosaves grouped by day with author;
  - preview read-only;
  - **Restore this version** (makes a new draft rev);
  - named versions and finals pinned at the top.

## S10 · Switch off, small screens, errors
- **Switch off:** `EmptyState` "Design Studio isn't turned on for your company." Sustainability while KPI tracking is off: the kind card is disabled with "Needs KPI tracking".
- **< 1280 px:** view pages, Page view, comments, download. No editing (RS R16).
- **Data unavailable** (e.g. market-based Scope 2): the element shows "Not reported" in the report's style and a link mark with the reason.

## Copy rules
RS copy rules apply. Additions:
- Say "design" for anything in the studio list, and "report" for a report design. Say "page", "template", "layout", "element", "style", "brand kit".
- Use GHG terms exactly: "Scope 1", "Scope 2 (location-based)", "Scope 3 Category 4: Upstream transportation and distribution", "tCO₂e", "biogenic CO₂ (reported separately)".
- Never say "Magic". AI copy: "Suggested by AI", "Based on", "Ask AI".
- Data marks: "Linked to approved data · 12 Apr 2026". Unlinked: "Typed data, not linked".
