# 04 · Decisions for Shyam

Each lane builds on the **default**. Changing a default later means a DS-0 follow-up plus the work listed for it.
- **Fixed by Shyam (2026-10-20):**
  - D1: one studio that absorbs RS;
  - the mockups use the ESGLite app tokens;
  - D8: the default check severities, including ISO 14064-1 clause 9.3.1.
- **Carried over from RS:** R4 (full free-form editing).
- **Open:** the rest are proposed defaults to accept or change.

| # | Question | Default (built) | If changed |
|---|---|---|---|
| D1 | One studio or two? | **Fixed:** one Design Studio for GHG and sustainability reports; RS absorbed (`00-plan` §4). | — |
| D2 | Build our own editor, or integrate Canva? | **Build our own** DOM/SVG editor (RS R5): `react-moveable` + `react-selecto`, our renderer, our PDF. Canva has no embeddable editor any more: the Canva Button is sunset after 2025-12-30. Connect only deep-links users out to canva.com, needs a Canva account per end user, and Autofill is a one-shot fill with no lineage (`research.md` §2.4). | **Add "Send to Canva" later:** export the PDF through the Connect Design Import API for clients who already use Canva. That is a one-way copy: numbers lose their links, and the result is not a final. A small add-on module. |
| D3 | Which Canva features are out of scope? | Real-time co-editing (presence only, RS R15); video, animation and audio; whiteboards; websites; a stock photo or video library; Magic Media video; background remover; CMYK; translation; DOCX/PPTX export; custom font upload. | Each is its own module. Translation needs per-language layouts. PPTX is images-only unless we build a native writer. |
| D4 | Who turns it on? | The Superadmin, per client: `company.design_studio_enabled`, default off, on the client Overview tab next to the KPI toggle. The GHG kind needs only this. The sustainability kind also needs `kpi_tracking_enabled`. | Separate switches per kind: two columns, same guard. |
| D5 | Who uses it? | Admins and Managers create and edit. Only a Manager or Superadmin generates a final, approves, or makes a share link. Users have no access. | Users may comment when @mentioned: a "commenter" role view in DS-13. |
| D6 | What does a GHG final need? | No pending emission entries in the period for the doc's sites (`GHG_PENDING_ENTRIES`), and no open error checks. There is no period lock for emissions today. | Add an emissions period lock first: a separate small plan, after which the check uses the lock. |
| D7 | Market-based Scope 2 | It isn't recorded (`src/kpi/auto/ghg.ts:88`). Templates show the location-based figure, plus a "Market-based: not reported" row with the reason. `SCOPE2_MARKET_MISSING` is a warning. `report_inputs.scope2_instruments` lets the user describe instruments in text. | Capture market-based Scope 2 (instruments, supplier factors, residual mix): a separate data plan. The binding then resolves. |
| D8 | GHG check severity | As in `01-contracts` §6. Missing GHG Protocol required items are errors; ISO items are warnings unless ISO 14064-1 conformance is selected. **Confirmed by Shyam 2026-10-20**, including the clause 9.3.1 responsible-person check (an error when ISO 14064-1 is selected). | Everything a warning (a softer gate), or everything an error (strict). |
| D9 | GHG templates at launch | Four: **Inventory** (GHG Protocol, A4, about 20 pages), **ISO 14064-1** (A4, adds categories 1–6 and uncertainty), **Board brief** (16:9, 8–10 slides), **One-page summary** (A4). Each comes in three looks (Classic, Light, Night) from the brand. | Fewer to launch faster (Inventory + Summary), or more (a BRSR P6 annex, a CDP-style C6/C7 pack). |
| D10 | AI models and budget | As RS R7 and R8: drafting `anthropic/claude-sonnet-5.5`, rewrites `google/gemini-3-flash-preview`. Per doc per day: $5 or 200 calls; per company per month: $50. Chat turns count as calls. | One model; or a higher budget for chat. |
| D11 | Brand voice | A free-text voice (≤ 3,000 chars) on the brand kit, edited by Managers, used in every writing prompt. An empty voice uses "plain, factual, third person". | Several named voices per company. |
| D12 | Print output | PDF (screen) and PDF (print) with 3 mm bleed and optional crop marks, RGB. PNG pages. No CMYK or PDF/X. | CMYK/PDF-X via Ghostscript post-processing; needs colour-profile testing. |
| D13 | Comments and tasks | Comments on pages and elements with @mentions of company users who have studio access. A comment can become a task with an assignee. Notifications go in-app and by email (existing `notificationService`). | Mention anyone in the company (needs the commenter view, D5). |
| D14 | Approval | "Request approval" picks one Manager as reviewer, with an optional due date. With `company.report_require_review` on, a final needs an approved request for the current rev. Off by default. | Several reviewers, or an ordered chain. |
| D15 | Share links | A read-only link to a stored proof or final PDF. Manager only; default expiry 14 days, at most 90; revocable; view count. No editing or commenting by link. | Comment-by-link (needs guest identity), or a live web edition (a separate module). |
| D16 | Version history | Autosaved snapshots every 10 minutes of active editing and on every named save. Kept 90 days or the last 200. Any of them can be restored as a new draft rev. Finals are never pruned. | Longer retention (a storage cost). |
| D17 | Elements and icons | Our own ESG element set (scope diagram, value-chain strip, SDG badges, pillar marks, data elements), Lucide icons (ISC), shapes, lines, frames, grids. Every asset's licence goes in `data/studio/LICENSES.md`. | Add a stock-photo API (Unsplash or Pexels): attribution rules, a separate module. |
| D18 | Formats | A4, A4 landscape, Letter, A5, 16:9, square, 1.91:1 social. One format per doc; Resize makes a linked copy. | Mixed formats in one doc: not recommended (pagination and the PDF get complicated). |
| D19 | Resize behaviour | Resize maps pages by layout kind to the target format's layouts and moves bound elements across. Free text is summarised by AI as a suggestion (with AI on), otherwise truncated with a check. The copy is a new doc linked to its source. | Pixel scaling only (faster, worse for deck and social). |
| D20 | Where does the old GHG PDF go? | It stays as it is (`/reports/ghg`), with a new **Design this report** button. Once DS-M2 is stable, decide whether the old PDF becomes a "Quick PDF" built from the Inventory template. | Replace it at DS-M1: lower maintenance, but a change for existing users. |
