# C05 · Product declaration export (claim)

Spec: ESG-lite_FE `docs/pcf/pages/C05-declaration-export/CLAUDE.md`. Builds on E1 `/pcf/studies` and the E1 API table entry `GET /pcf/studies/:id/export?format=pdf-data|csv|pact`.

## Backend (this PR, C05 1/2)
- `GET /pcf/studies/:id/export?format=pdf-data` returns everything the PDF declaration shows (product, site, period, boundary, standard, stage totals, lines, data quality, cut-offs, allocation, review status), with the same licensed-value redaction as the study endpoints.
- `format=pact` returns a PACT Technical Specifications v3 `ProductFootprint`, validated against the published v3.0.3 schema before it is sent. Only approved, published or superseded (exported as Deprecated) footprints export as PACT JSON.
- `format=csv` returns the inputs and results for the buyer's own checks; a draft is marked DRAFT in the file.
- API test with the pilot-style study validates the PACT JSON against the vendored schema in CI.

## Frontend (ESG-lite_FE, C05 2/2)
- Export page for a footprint: format choice, DRAFT notice, branded PDF declaration (cover, summary, inputs and data quality, method notes) built on P10's `pdfTheme(brand)`, PACT JSON and CSV downloads.
