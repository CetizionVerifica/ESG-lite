# C04 · Material factors library (claim)

Spec: ESG-lite_FE `docs/pcf/pages/C04-material-factors/CLAUDE.md`. Builds on E1 `/pcf/material-factors`.

## Backend (this PR, C04 1/2)
- `GET /pcf/material-factors` adds `used_by` (footprints using the factor) and `used_by_approved` (approved or published ones).
- `GET /pcf/material-factors/:id` returns the factor plus its usage list (study, product, version, status), scoped to what the caller can see.
- One factor per name × geography × source year × company: create, edit and import refuse a duplicate with 409 and the existing row's id.
- `POST /pcf/material-factors/import` takes a list of rows, validates them all, and saves all or none.

## Frontend (ESG-lite_FE, C04 2/2)
- `/factors/materials` page for Superadmin and Manager: FilterBar, DataTable, Drawer with metadata and usage, add/edit, Excel import with a column review step.
