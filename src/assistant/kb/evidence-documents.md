Evidence is the bill, invoice or other document behind an entry. Attaching it helps your manager check and approve the entry.

**When you add data (Users)**
1. In [Add data](/data/new), open **Evidence** on a row.
2. Drop or pick files: PDF, image or spreadsheet, up to 10 MB each.
3. Files are attached when you send. The review step shows each row's evidence, for example "2 files, attached on send".

Rows made with **Start from a bill** get the bill attached automatically.

If a file couldn't be attached, the success screen says so. Attach it from [My entries](/data/mine).

**After sending (Users)**
1. Open the entry in [My entries](/data/mine).
2. Drop or pick files under **Add evidence**. They're saved straight away.
3. To take a file off, choose **Remove**, then **Remove file**.

You can add or remove evidence only while an entry is Pending or Rejected. For a Rejected entry, resubmit it when you're done.

**The same file on two entries**
If a file already backs another entry for the same period, the review step warns "This evidence already backs another entry". If it's the same purchase, it would be counted twice. You can still send.

**For Managers**
- Open an entry in [Approvals](/data/approvals) and look at its **Evidence** section to open each document.
- A Pending entry without any document is held under **Needs attention** with the reason "No evidence", so you can look at it before approving.
